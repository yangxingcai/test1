# Python游戏集合

## 项目概述
这是一个使用Python和pygame开发的游戏集合，包含俄罗斯方块和贪吃蛇两个经典游戏，采用苹果设计规范。

## 技术栈
- Python 3.13.7
- pygame 2.6.1

## 游戏列表

### 1. 俄罗斯方块 (teris.py)
- ✅ 7种经典俄罗斯方块形状（I、O、T、S、Z、J、L）
- ✅ 方块旋转和移动
- ✅ 行消除机制
- ✅ 计分系统
- ✅ 等级系统（每10行升一级）
- ✅ 下一个方块预览
- ✅ 游戏结束检测
- ✅ 重新开始功能
- ✅ 暂停功能

**游戏控制：**
- **← →** 左右移动方块
- **↓** 软降（加速下降）
- **↑** 旋转方块
- **空格** 硬降（瞬间到底）
- **P** 暂停/继续
- **ESC** 退出游戏
- **R** 游戏结束后重新开始

### 2. 贪吃蛇 (snake_game.py)
- ✅ 经典贪吃蛇游戏
- ✅ 蛇身增长机制
- ✅ 食物生成系统
- ✅ 碰撞检测
- ✅ 计分系统
- ✅ 速度递增
- ✅ 游戏结束检测
- ✅ 重新开始功能
- ✅ 暂停功能

**游戏控制：**
- **↑ ↓ ← →** 控制蛇的移动方向
- **空格** 暂停/继续
- **R** 重新开始
- **ESC** 退出游戏

## 运行方法

### 俄罗斯方块
```bash
python teris.py
```

### 贪吃蛇
```bash
python snake_game.py
```

## 设计特色

### 苹果设计规范应用
- **色彩系统**：使用iOS系统颜色
- **字体层次**：标题、正文、说明文字层次分明
- **圆角设计**：所有元素采用圆角矩形
- **卡片布局**：信息以卡片形式组织
- **模态框**：游戏结束和暂停使用苹果风格模态框
- **视觉层次**：清晰的信息分组和颜色对比

### 用户体验
- **直观控制**：清晰的控制说明
- **状态反馈**：明确的游戏状态显示
- **暂停功能**：随时可以暂停游戏
- **重新开始**：游戏结束后可以快速重新开始
